Conectar como unidad de red (WebDAV)

URL: {{ webdav_url }} — usuario: {{ current_user.username }}, contraseña: una "contraseña de aplicacion" de abajo (nunca tu contraseña principal).

Windows: Explorador de archivos → clic derecho en "Este equipo" → "Conectar a unidad de red" → pega la URL, marca "Conectar con credenciales diferentes" e ingresa usuario y contraseña. No uses "Agregar una ubicacion de red": ese asistente falla con el error "el nombre de carpeta no parece valido" en este tipo de configuracion. Si un primer intento falla con el error 0x80070043 "no se encuentra el nombre de red", Windows recuerda ese fallo y lo repetira aunque el problema ya este resuelto: reinicia el servicio WebClient (net stop webclient && net start webclient en un simbolo del sistema como administrador) o reinicia el equipo antes de volver a intentarlo.
macOS: Finder → Ir → Conectar al servidor → pega la URL.
Linux: davfs2 o el gestor de archivos (Nautilus/Dolphin) con "Conectar a servidor".
Espacio usado/disponible: el indicador de espacio que muestra Windows sobre este cloud es conocido por mostrar valores incorrectos o no mostrarlos. Usa el indicador en la barra lateral de esta página como la cifra real y actualizada.
